# Feature inventory at the navigation milestone

| Area | Implementation and evidence | Remaining check or improvement |
| --- | --- | --- |
| Workspace and results navigation | Shared skip links, persistent three-theme control, compact research links, zoom and display controls, observation selector, side-by-side cutouts. Browser smoke passed on the demo field. A public-origin browser simulation disables local FITS selection and rejects loopback requests from legacy deep links. | Human screen reader audit, actual public-origin browser check, and broader real-data workflow. |
| Viewer, timeline, compare, measurement and exports | Existing player and features modules. Offline scripts exercise mock frames, comparison, measurement and export helpers. Browser checks loaded nine observed Barnard D2 frames and three independent Epsilon Indi B D6 frames at three widths, stepped the timeline, rendered difference and paired cutouts, measured each sequence and exported finite Jy values with provenance. See REAL_D6_REPLICATION.md. | Exercise more fields and detectors; compare measured flux and uncertainty with an independent method. |
| FITS cutouts, resampling, masking and photometry | FastAPI and backend/spherex, with generated FITS fixtures in backend/tests. FITS header provenance reaches workspace labels and exports. Three D6 cutouts were acquired from named IRSA level-2 products with recorded URLs and SHA-256 hashes. A separate native-pixel calculation matched their backend fluxes within 5.1%; one aperture was flagged. The API now identifies its resampled sky-scatter error model, and the UI calls resulting S/N nominal. | Calibrate uncertainty and absolute flux independently, and test more image flags and products. |
| Find Movers and parallax | Existing detector and fit modules, profile distance fit, independent ephemeris test, recorded injection recovery on nine observed backgrounds. Planet X Lab displays the experiment with uncertainty and controls. | Wider, independent fields and more injected trials. |
| Spectra and detector comparison | Existing spectrum and compare modules with offline tests. | Recheck real-data uncertainty and calibration before changing outputs. |
| SIMBAD, SkyBoT and sky map | Existing catalogue, skybot and skyContext integrations. Offline logic checks do not establish service availability. | Exercise live success and failure paths. |
| Results dashboard | Saved validation charts, importable candidate JSON, searchable explorer, centroid evidence and offline report. A JSON export preserves fit positions and frame keys. Public Results hides archived real-FITS workspace links while keeping synthetic candidate links; local Results keeps real-data links. Node and browser round trips pass. | Validate more real candidate associations and report wording against independent records. |
| Sky Explorer and simulator | Sky Explorer loads a saved IRSA SIA2 field and queries the backend for current footprints. The simulator renders adjustable observer geometry. On the public static site, Sky Explorer and Planet X Lab explain that observed FITS workspace links require a local backend; locally served links remain available. | Live archive failure-path checks and independent geometry comparison. |
