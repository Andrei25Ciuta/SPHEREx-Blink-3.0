Read `AGENTS.md` first. Update this file after every working session. Last update: **10 Nov 2026**, branch `blink-2.0`.
Verify what is written here against `git log` and the test commands in `AGENTS.md`; do not trust it blindly.

## Where it stands

**Phase 0 (audit) done. Phase 10 (hardening) done, with limits: Find movers and the Planet X search run in a worker (the same task on the page if no worker can be had), three benchmarks with golden digests of their output, an end-to-end smoke test of the page in headless Chrome (Node only, 15 checks, its own CI job, which passed on GitHub), and the documents BENCHMARKS, DEPLOYMENT, CONTRIBUTING, CHANGELOG; no search got faster, Playwright was not used, nothing is deployed. Phase 9 (explainer) done, with limits: rule-based, every sentence cites measured values, a validator refuses the rest; no language model connected. Phase 8 (Solar System simulator) done, with limits: eight planets checked against JPL Horizons, the Earth of the parallax search, a scientific mode and an educational one labelled NOT TO SCALE. Phase 7 (sky explorer with real footprints) done, with limits: the footprints of the image files, an all-sky map, fields at true scale; not the survey's own. Phase 6 (spectral and multi-detector) done, with limits: the six detectors side by side with the missing ones marked, the uncertainty as a band that breaks at gaps. Phase 5 (Planet X Lab) done, with limits: three motions compared by BIC, the distance only when constrained, and a completeness map of the search from synthetic bodies injected into real images, measured on the Barnard D2 field (VALIDATION 16). Phase 2 (workspace) done, with limits: the viewer, the timeline, the three-panel layout (search / picture / inspector, side panels that close) and the inspector are in; a view that follows a candidate, layer order and opacity are in too; real pixel values outside Blink mode and remembering the layer settings are not. Phase 3 (results dashboard and candidate explorer) mostly done: provenance, the candidate table and plot, the six real fields' sources made by a command, and an origin line under each of sections 1-10 (the command and the VALIDATION.md section); the numbers of sections 1-10 are still typed into `real_results.json` from the reports of those commands. Phase 1 (design foundation) mostly done. Phase 4 (scientific pipeline) mostly done: positions, velocities and fluxes carry errors checked against repeated injections and real stars (VALIDATION §15); a PSF-fit centroid is in but worse than the windowed one on the real images, so it is off by default (15.7); the parallax search's 0.15 px error is not calibrated on real dots.** Phases are defined in
[IMPLEMENTATION_ROADMAP.md](IMPLEMENTATION_ROADMAP.md).

## Remaining in Phase 4

- A **PSF-fit centroid is built and measured, and is off by default** (VALIDATION 15.7): 1.0-1.2 times the Cramer-Rao limit on injected stars, but on the real images it scatters more than the windowed centroid (0.061 against 0.046 px at S/N 20-60). The next step would be the real PSF (the file's PSF extension) instead of a Gaussian, and a PSF width per image instead of the cautious default.
- The **parallax search** still uses its 0.15 px floor (to be calibrated with injections in the Planet X Lab, Phase 5); Epsilon Indi B's 0.5″/yr offset from the catalogue is unexplained (a possible cause from memory, not tested: the unresolved binary).
